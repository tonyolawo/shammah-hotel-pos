# Backlog – Future Hotel POS Roles

The following roles and associated use‑cases are identified for future implementation. They are kept in a backlog file so they can be prioritized later.

| Role | Typical Use‑Cases (future) |
|------|----------------------------|
| **Housekeeping Staff** | • Log room cleaning status<br>• Record minibar replenishment<br>• Request maintenance via POS interface |
| **Restaurant / Bar Staff** | • Take dine‑in or room‑service orders<br>• Split checks, apply service charges<br>• Send tickets to kitchen, track table status |
| **Hotel Manager / Owner** | • Consolidated dashboards across all departments<br>• Approve discounts, view audit logs, configure pricing rules |

> **Note:** These roles will be added to the system in subsequent development phases after the core front‑desk, accountant, and guest functionality is stable.
